# Platform icon sources

- `apple.svg`: Apple mark from [Simple Icons](https://simpleicons.org/?q=apple), rendered in white for the dark interface.
- `android.svg`: Android mark from [Simple Icons](https://simpleicons.org/?q=android), rendered in Android green (`#3DDC84`).
- `github.svg`: GitHub mark from [Simple Icons](https://simpleicons.org/?q=github), rendered in GitHub black (`#181717`).
- `windows.svg`: Local four-pane Windows platform glyph, rendered in Microsoft blue (`#0078D4`).
- `web.svg`: Local globe glyph, rendered in Better Keep yellow (`#E7FF00`).

The marks identify their respective platforms; Better Keep does not claim ownership of Apple, Android, or Windows trademarks.
